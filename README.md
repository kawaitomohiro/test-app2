# 3択クイズ

HTML・CSS・JavaScriptで作った、全5問の3択クイズアプリです。

## ローカルでの実行

`index.html`をブラウザーで開くと遊べます。外部ライブラリーは使用していません。

## GitHub Pagesへの公開

`main`ブランチにpushすると、GitHub Actionsがサイトを自動でデプロイします。リポジトリの **Settings → Pages → Build and deployment** で、公開元が **GitHub Actions** に設定されていることを確認してください。デプロイ先のURLは、Actionsの実行結果とPages設定に表示されます。
