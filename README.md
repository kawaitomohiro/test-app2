# 3択クイズ

HTML・CSS・JavaScriptで作った、全5問の3択クイズアプリです。

## ローカルでの実行

`index.html`をブラウザーで開くと遊べます。外部ライブラリーは使用していません。

## GitHub Pagesへの公開

初回公開時は、リポジトリ管理者が **Settings → Pages → Build and deployment** で公開元を **GitHub Actions** に設定してください。Pagesサイトを有効にした後は、`main`ブランチへのpushでGitHub Actionsが自動デプロイします。デプロイ先のURLは、Actionsの実行結果とPages設定に表示されます。
